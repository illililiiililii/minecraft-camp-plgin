# CampfireCoop 1.8.0

Paper 1.21.11 / Java 21 이상. 3~4인 협동 생존용 플러그인입니다.

## 이번 패치

- 장비의 기본 내구도 소모와 보급 장비 사용 횟수 제한을 제거했습니다. 기존 보급 장비도 접속·사용·배송 시 제한을 제거합니다.
- 보급 확률: 광물 85%, 검 5%, 효율 VI 도구 5%, 보호 VI 갑옷 5%.
- 광물 내 비중: 철 35%, 금 25%, 청금석 20%, 다이아 19.5%, 네더라이트 주괴 0.5%. 주괴는 전체 택배 기준 0.425%입니다.
- 철은 3~6개, 금은 2~4개, 청금석은 4~8개, 다이아·네더라이트 주괴는 1개씩 지급합니다.
- 검·곡괭이·도끼·삽·괭이는 나무/돌/철/금/다이아/네더라이트, 효율 도구에는 가위도 포함합니다. 검은 날카로움 VII입니다.
- 갑옷은 가죽/사슬/철/금/다이아/네더라이트의 머리·상의·하의·신발입니다. 바닐라에 없는 나무·돌 갑옷은 만들지 않습니다.
- 장비 재질 비중: 앞 두 재질 각 25%, 철 25%, 금 15%, 다이아 9.5%, 네더라이트 0.5%. 가위는 별도 20% 추첨입니다.
- /camp delivery pause: 본인 택배 배달·수령 정지. 이미 내려오던 택배도 보관함으로 돌립니다. 온라인 보급 적립은 유지합니다.
- /camp delivery resume: 재개. 지상에서 밀린 택배가 순차 배달됩니다.
- /camp delivery status: 정지 상태와 누적 개수 확인. 정지 설정은 재접속·패치·서버 재시작 후에도 유지합니다.
- 안내서와 HUD에 새 규칙과 정지 상태를 반영했습니다.

## 기존 기능

협동 목표·보상, 공용 기지 귀환, 하늘 보급 누적, 사망 아이템 회수 상자, 찹트리, 재심기, 정렬, 원격 제작대·엔더 상자, 친구 이동 요청, 원정, 현상수배, 파티 콤보, 낚시 보너스와 안내서를 포함합니다. /camp help와 /camp book을 확인하세요.

## 빌드·배포

mvn package (JUnit/MockBukkit 테스트 62개 통과).

plugins/CampfireCoop-Loader.jar는 고정 로더이며, 실제 기능은 plugins/CampfireCoop/runtime.jar에 있습니다. 기존 로더 서버는 Apply-Update.ps1의 -ServerPath와 -RuntimeJar 인자로 새 모듈을 전달하면 5초 이내 무중단 적용합니다. 기능 교체 중 진행 중인 원정과 대기 이동은 취소되며 아이템·월드·택배는 보존됩니다.

생성되는 world, plugins 데이터, 접속 키와 서버 네트워크 폴더는 공개 저장소에 포함하지 않습니다.
